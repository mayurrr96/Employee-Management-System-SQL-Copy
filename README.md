# Employee Management System | MySQL

## 📌 Project Overview

This project demonstrates the design and implementation of an Employee Management System using MySQL. It focuses on managing employee and department information through relational database concepts and SQL queries.

## 🎯 Project Objectives

- Design and manage relational database tables.
- Store employee and department information.
- Establish relationships between tables.
- Retrieve and analyze employee records using SQL queries.
- Practice database management and data manipulation.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 🗄️ Database Structure

The project includes two main tables:

**1. employee_master**
- Employee details and department references.

**2. department_master**
- Department information and identifiers.

## 💻 SQL Concepts Practiced

- CREATE DATABASE and CREATE TABLE
- INSERT, UPDATE and DELETE
- PRIMARY KEY and FOREIGN KEY
- SELECT, WHERE and ORDER BY
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate functions
- Database relationships

## 📊 Project Highlights

- Created a relational database structure.
- Managed employee and department records.
- Connected tables using primary and foreign keys.
- Retrieved meaningful information using SQL queries.
- Practiced data analysis through SQL aggregations.

- SQL script containing database creation, table structures, sample records and queries.
